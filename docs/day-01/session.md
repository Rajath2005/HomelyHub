## 1. Session Overview

Day 1 was the kickoff session for the **HomelyHub MERN Stack Internship 2026** conducted by **WebStack Academy**.

The session introduced the internship structure, learning methodology, project objectives, technology stack, web application architecture, and the overall development journey.

The central goal of the internship is to gain practical, project-based experience by building **HomelyHub**, a full-stack property booking platform using the MERN stack.

---

## 2. About the Internship

The internship follows a **hands-on, project-based learning model** designed to bridge the gap between theoretical knowledge and real-world software development.

The program focuses on building practical development skills through continuous coding, debugging, implementation, and project work.

### Internship Model

- 30-day hands-on learning program
- 15 live technical sessions
- Sessions conducted on alternate days
- Live sessions from **7:00 PM to 8:30 PM IST**
- Learning through project implementation
- LMS-based study materials
- Discussion forum for doubts and collaboration
- Weekly quizzes
- Project submission
- Internship completion certificate

The program is provided at no cost and does not include a stipend or formal placement support.

---

## 3. HomelyHub Project

### Project Objective

The primary project of the internship is **HomelyHub**, a property booking platform inspired by applications such as **Airbnb** and **MakeMyTrip**.

The project is intended to provide practical experience in designing and developing a complete web application.

### Core Project Areas

HomelyHub is designed around functionality such as:

- Property search
- Property filtering
- Property booking
- User accounts
- Property hosting and rental
- Profile management
- Data-driven application features
- AI-powered functionality

The project follows a full-stack architecture where the frontend, backend, and database work together through APIs.

---

## 4. MERN Stack

HomelyHub uses the **MERN stack** as its primary technology foundation.

| Technology | Role |
|---|---|
| **MongoDB** | NoSQL database for application data |
| **Express.js** | Backend framework for APIs |
| **React.js** | Frontend library for the user interface |
| **Node.js** | JavaScript runtime for server-side development |
